# Pembetulan login demo Render

1. Gantikan fail app.py, templates/login.html dan render.yaml dalam repository GitHub.
2. Di Render > Web Service > Environment, tambah DEMO_ADMIN_PASSWORD, DEMO_GURU_PASSWORD dan DEMO_IBU_PASSWORD dengan tiga kata laluan kuat BERBEZA. Jangan simpan nilai ini dalam GitHub.
3. Pastikan Root Directory = e-peperiksaan-kislb-demo-online-render.
4. Deploy semula. Username ialah admin, guru dan ibu.
5. Akaun sedia ada akan dikemas kini setiap kali servis bermula. Data demo SQLite pada Render Free boleh hilang apabila servis restart/deploy.
6. Sebelum kongsi pautan dengan klien, uji setiap peranan, dan jangan kongsi kata laluan admin jika tidak perlu.
