# Demo online melalui Render

1. Muat naik kandungan folder ini ke repositori GitHub **private** yang baharu. Pastikan `render.yaml` di akar repositori (bukan dalam subfolder).
2. Di Render pilih New > Blueprint, sambungkan repositori, semak konfigurasi dan deploy.
3. Selepas deploy, buka URL `.onrender.com` yang diberikan Render.
4. Rujuk `PANDUAN_DEMO_KLIEN.txt` untuk akaun demo. Tukar kata laluan demo sebelum berkongsi secara luas.

**Penting:** Render Free mempunyai storan sementara. Data demo akan kembali kepada data seed apabila instance dibina semula atau di-restart; jangan gunakan untuk data sebenar. Free service mungkin mengambil masa untuk bangun selepas tidak aktif. Tiada data production disambungkan. `DEMO_SECRET_KEY` dijana automatik melalui Render Blueprint.

Sebelum paparan kepada klien, uji login semua peranan, slip, markah, dan semak tiada data sebenar. Jangan masukkan maklumat sebenar murid dalam demo.
